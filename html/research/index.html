Padegh Sangbusarakum

Research ที่สนใจ

มีความสนใจเรื่อง คือ ด้าน Security ของ อุปกรณ์ Edge Computing ซึ่งโดยทั่วไป จะเป็น Devie ขนาดเล็ก และ มี memory ไม่มากนัก ซึ่งปัจจุบันในระบบควบคุม ในโรงงานอุตสาหกรรมนั้น กำลังอยู่ในช่วงเปลี่ยนผ่านมาเป็น Industrial 4.0 ซึ่งโรงงานก็จะต้องพัฒนา ให้เป็น Digitalize มากขึ้น เช่น IIot (Industrial Internet of Thing ) ก็จะต้องเกิดขึ้นอย่างแน่นอนด้วยเหตุนี้ จึงเป็นแรงดึงดูดให้ Hacker ทุกระดับ ย่อมเกิดความท้าทาย และ ต้องปฏิบัติการที่ อันตรายต่อระบบอย่างแ่นอน
